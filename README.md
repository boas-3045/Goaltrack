# Goalspace

A responsive personal goal and habit tracker built with HTML, CSS, and vanilla JavaScript.

## Run

Open `index.html` in a browser or host this repository as a static website. User data is saved locally in the browser.

## Project files

- `index.html` — welcome screen and workspace shell
- `css/styles.css` — responsive styling
- `js/app.js` — workspace pages and interactions
- `js/storage.js` — local data storage and sample data
- `assets/raggiana-bird-of-paradise.jpg` — welcome page background image
